# タスクの実行

ユーザーが指定したタスクID（T01〜T12。指定が無ければ、WORKLOG と `git log --oneline main..HEAD` から未完了の最初のタスク）を、`AGENTS.md` のルールと禁止事項に従って実装してください。

1. `docs/dev/v1.6.6/INSTRUCTIONS.md` の該当タスクの節と §5（横断ルール）を読み直す。関係するソースとテストを読む。
2. 実装する。指示にない変更はしない。
3. 指示されたテストを追加し、指定された受け入れテストの `it.skip` を外す（期待値は変更しない）。
4. `npx vitest run <関係するテストファイル>` で確認し、次に `npm test` を実行して全体が緑であることを確認する。
   - ルール JSON を変更した場合は `npm run spec:generate` を実行してから `npm test`。
   - 同じテストが3回続けて直らない場合は、そのタスクを「未完了」として記録し、止まって報告する。
5. `docs/dev/v1.6.6/WORKLOG.md` に、指定の形式（`## Txx …`）で記録を追記する。
6. `git add` と `git commit -m "[Txx] <要約> (<指摘ID>)"` でコミットする。push はしない。
7. 実施内容・テスト結果（passed / skipped / failed の件数）・判断したことを短く報告して止まる。
