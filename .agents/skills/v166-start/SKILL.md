# v1.6.6 開発の開始

あなたはこのリポジトリの開発担当です。`AGENTS.md` のルールと禁止事項に従ってください。

1. `AGENTS.md` と `docs/dev/v1.6.6/INSTRUCTIONS.md` を全文読み、続けて `docs/REVIEW_v1.6.5.md` の第1〜3章のうち、T01〜T12 に対応する指摘（SPEC-01/02/04/06/09/16, DOC-01/02/08/09, IMPL-01/02/03/04）を読む。
2. 次のコマンドで現在の状態を確認する: `git branch --show-current`、`git status --short`、`node -v`。
3. 指示書 §0 の前提条件を順に確認し、`npm test` と `npm run build` の結果を記録する（`npm ci` は作業者が実行済み）。
   - 前提を満たさない項目があれば、作業を始めずに状況を報告して止まる。
4. `docs/dev/v1.6.6/WORKLOG.md` に「## T00 ベースライン」として、前提確認の結果（テスト件数を含む）を追記する。
5. T01〜T12 の作業計画を、タスクごとに「変更予定ファイル」「追加するテスト」「懸念点」の3点で短く示す。
6. 計画を示したら止まり、「進めて」の指示を待つ。
